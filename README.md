# Assets folder

Drop your real images here using these exact filenames so the site picks them up automatically:

- `profile.jpg` — your photo for the hero section (recommended: square-ish or 4:5 portrait, at least 600px wide).
- `project-1.jpg` — optional thumbnail for the EcoTrack project card.
- `project-2.jpg` — optional thumbnail for the Game Development & Web Project card.

If `profile.jpg` is missing, the hero section automatically falls back to a clean "GT" monogram — nothing will look broken.

Project thumbnails are optional. If you add them, open `index.html` and swap the `.project-media` placeholder `<span>` in each project card for an `<img src="assets/project-1.jpg" alt="...">` tag — the CSS already supports it.
